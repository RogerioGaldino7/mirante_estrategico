# Mirante Estrategico Tecpar

Dashboard web client-side para consolidar bases CSV exportadas do ERP Benner/Cubo e apoiar a visualizacao de faturamento, metas, OVs, clientes, fidelidade, classificacao setorial e exportacoes analiticas para IA.

## Publicacao no Vercel

- Framework Preset: `Other`
- Build Command: `npm run build`
- Output Directory: `dist`

## Privacidade

Bases CSV, exportacoes de IA e arquivos gerados localmente nao devem ser publicados no repositorio.
